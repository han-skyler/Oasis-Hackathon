## ✨ 주요 기능

- **🤖 AI 챗봇:** 사용자와 대화하며 정서적 지지를 제공하고, 치매 관련 정보를 답변해주는 AI 챗봇 기능
- **🧠 인지훈련 게임:** 기억력, 집중력 등 인지 능력을 향상시키는 다양한 미니게임 제공
- **🩺 치매 자가진단:** 간단한 테스트로 자신의 인지 건강 상태 점검
- **🗺️ 주변 치매센터 찾기:** 카카오맵 API를 활용해 주변 치매안심센터 위치 확인
- **🔐 소셜 로그인:** Google, Kakao 계정을 이용한 간편 로그인/회원가입 기능

## ⚙️ 빌드 방법

1. **저장소 복제**
   ```bash
   git clone https://github.com/your-repository/Oasis-Hackathon.git
	```
2. **Android Studio에서 열기**

   * `Open an existing project`로 복제된 프로젝트 폴더 열기
3. **API 키 설정**

   * `app/google-services.json` → Firebase에서 발급받은 파일로 교체
   * `AndroidManifest.xml` 또는 `build.gradle`에 카카오맵 API 키 등 인증 키 추가
4. **빌드 및 실행**

   * Gradle 동기화 완료 후, 에뮬레이터 또는 실제 기기에서 앱 실행
